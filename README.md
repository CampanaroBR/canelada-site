# Canelada: landing page

Landing page for **Canelada**, an invite-only app for weekly pickup football games in Salvador, Brazil. After each game the group votes on who was the star, the wall and the "bagre" (catfish) of the night. The votes turn into rankings, medals and a week of banter.

**Live:** https://campanarobr.github.io/canelada-site/ · **App:** https://canelada.app.br · **Design system:** https://campanarobr.github.io/canelada/

- Built on the Canelada design system: tokens, Barlow + Google Sans, DS components and Lucide icons
- Bilingual PT/EN with flags, and a live scoreboard header that counts down to the next game or the end of voting
- Loader where the stadium floodlights switch on tower by tower (photo pair masked on canvas)
- Real app screens in a 3D phone gallery, an interactive team draw, medals that unlock as you scroll, an odometer with the group's real numbers
- Plain HTML, CSS and JavaScript with GSAP and Lenis. No build step.

Product, design and code by Arthur Fonseca, 2026. Characters are the app's own mascots; scene imagery generated with AI and art-directed by the author. Players shown are fictional.
